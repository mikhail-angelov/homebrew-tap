# mikhail-angelov/tap

Homebrew tap for my apps.

```sh
brew install --cask mikhail-angelov/tap/vadic
```

| Cask | Description |
|---|---|
| [vadic](https://github.com/mikhail-angelov/vadic) | Local push-to-talk dictation for macOS powered by whisper.cpp |

Casks are updated automatically by each project's release workflow.
